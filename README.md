# Remix of Arval Heritage Collection

Create a premium ecommerce redesign for "Arval Argenti Valenza", an Italian historic silverware company founded in 1967.

IMPORTANT

Do NOT redesign the current website literally.

Use the existing website only as content reference.

Current website:

https://www.arvalargenti.com/

Visual inspiration only:

https://www.zanolli.com/

The result must have its own identity.

Think of an elegant Italian luxury boutique specialized in silver gifts, wedding gifts, home décor and precious objects.

VISUAL LANGUAGE

Use real photography from the existing Arval website whenever possible.

Create layouts around those images.

The design should elevate the existing content rather than replacing it.

━━━━━━━━━━━━━━━━━━━━━━━━━━

DO NOT

Do not create a generic Prestashop homepage.

Do not overcrowd the homepage.

Do not show hundreds of products immediately.

Avoid small images.

Avoid blue gradients.

Avoid old ecommerce layouts.

Avoid boxed design.

Avoid dense navigation.

INSPIRATION

Georg Jensen

Luxury Italian boutiques

High-end editorial ecommerce

Think of a website that could win an Awwwards Honorable Mention while remaining practical for a future Prestashop or Shopify implementation.

Create a complete desktop homepage, mobile homepage and reusable design system.

Use the existing Arval website assets (logo, product photography, historical content and categories) as the content source, but reinterpret them with the visual quality, spacing and storytelling of a contemporary luxury ecommerce. The goal is evolution, not imitation. Every section should encourage discovery and emotion before selling products.
